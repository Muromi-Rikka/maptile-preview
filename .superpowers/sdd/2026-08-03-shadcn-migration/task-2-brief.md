# Task 2: Shadcn Initialization

**Files:**

- Create: `src/components.json` (generated by shadcn)
- Create: `src/lib/utils.ts` (generated by shadcn)
- Modify: `src/globals.css` (theme variables added)

**Interfaces:**

- Produces: shadcn configuration, `cn()` utility function, cosmic-night theme CSS variables

**Steps:**

1. Initialize shadcn:

```bash
pnpm dlx shadcn@latest init
```

When prompted, select:

- Style: New York
- Base color: neutral
- CSS variables: yes

2. Add cosmic-night theme:

```bash
pnpm dlx shadcn@latest add https://tweakcn.com/r/themes/cosmic-night.json
```

3. Add shadcn components:

```bash
pnpm dlx shadcn@latest add button card scroll-area
```

4. Verify generated files exist:

```bash
ls src/components/ui/
ls src/lib/utils.ts
```

5. Commit:

```bash
git add src/components.json src/lib/utils.ts src/components/ui/ src/globals.css
git commit -m "feat: initialize shadcn with cosmic-night theme"
```
